## Defects found and fixed

XTD-to-XTD resampling previously required an adjacent cell even at an exact
grid coordinate. A wet coastal node next to land therefore became unknown and
each authoring generation eroded the mask. Exact-node brackets now sample only
that node. A regression test covers a single wet node beside land.

The initial 0.125-degree author exceeded the signed coefficient range at 0.2 mm
quantisation. The global format now uses 0.5 mm, covering amplitudes through
16.3835 m while remaining below source-data uncertainty. Overflow still fails
authoring.
