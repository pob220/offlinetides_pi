# X-Tidal v0.7 Chart Datum qualification

Date: 2026-08-21

## Decision

V0.7 is accepted for controlled GUI field testing as a secondary offline
astronomical-tide source. It may display height above Chart Datum where the
authenticated transform is supported. It is not approved to alter charted
soundings, depth shading, alarms or under-keel-clearance calculations.

The UI defaults to `Height above Chart Datum` and offers `Level relative to
model mean sea level`. Both choices use the same UTC harmonic prediction; the
selector changes only the vertical display reference. Missing datum support is
unknown and prompts the user to select MSL rather than assuming a zero offset.

## Method and scientific boundary

The operational harmonics remain referenced to model MSL. An independent
tiled component supplies the additive MSL-to-local-Chart-Datum transform,
uncertainty, datum realization, support class, station distance and station
count. The authoring graph respects the water mask and uses a shorter reach
for estuary stations. This is a lightweight observation-constrained
transformation, not a global hydrodynamic datum model.

This follows the separation used by modern hydrographic products: water-level
predictions and vertical reference transformations are distinct concerns. IHO
S-104 defines the water-level product family, while NOAA VDatum likewise
publishes transformation uncertainty rather than presenting a datum shift as
exact. The model also preserves national datum families instead of equating
LAT, MLLW, LLWLT and NLLW.

- IHO S-104 product specification registry:
  https://registry.iho.int/productspec/view.do?idx=209&product_ID=S-104
- NOAA VDatum uncertainty guidance:
  https://www.geodesy.noaa.gov/docs/est_uncertainties.html
- Global LAT modelling background:
  https://discovery.ucl.ac.uk/id/eprint/1397707/

## Field safeguards

- Every graph axis, event and selected value says Chart Datum or model MSL.
- The cursor states the national realization family and transform uncertainty.
- The MSL option retains the warning against direct chart-depth/UKC use.
- Unsupported transforms fail closed.
- Weather surge, river flow and observed sea-level anomaly are not silently
  manufactured by an astronomical model.
- Chart-depth mutation, adjusted soundings and UKC integration remain absent.
