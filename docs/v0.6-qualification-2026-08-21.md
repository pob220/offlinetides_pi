# X-Tidal v0.6 global qualification

Date: 2026-08-21

## Release decision

V0.6 is accepted as a field-testable secondary astronomical-tide product for
event timing, curve shape and tidal range. It is not accepted as a source of
height above Chart Datum and cannot be used directly for charted-depth,
drying-height or under-keel-clearance calculations. The plugin displays and
enforces that distinction.

This boundary is deliberate. The global package datum is model mean sea level.
Changing harmonic phases and amplitudes cannot establish local Chart Datum.
The existing bounded v0.4 Chart Datum product remains the more appropriate
developer test at its supported UK cells.

their errors exceed the observed spread between local authoritative sources.

## Defects found in qualification

The first 40-term build regressed tidal range badly. The cause was not model
selection: lambda-2 (`lda2`) had an incorrect frequency and L2 nodal class in
the prediction engine. It now uses the IHO lambda-2 speed and the M2 nodal
class. The 13 additional terms and their nodal relations have direct engine
tests. TICON aliases (`EP2`, `LM2`, `MI2`, `NI2`, `MKS`) are normalised to the
runtime canonical names.

The station anchoring path also had a fallback decision based on global map
state rather than the current observation. This is now per observation and is
covered by the assimilation tests.

## Field safeguards

- Every number and HW/LW marker states `CD`, `MSL`, or the package datum.
- Non-Chart-Datum curves display a persistent warning against depth and UKC
  arithmetic.
- The cursor displays harmonic uncertainty, nearest-observation distance,
  observation count and whether support is background-only, observation
  constrained, estuary constrained or independent-model fallback.
- Masked/land/outside-coverage points remain unknown.
- Missing quality remains visibly unavailable rather than silently good.
- No depth shading or sounded-depth adjustment is enabled.
