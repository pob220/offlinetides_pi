## Datum audit method

The audit looks for a near-constant signed event-height error with small
event-to-event spread and a substantially correct tidal range. This is a
diagnostic signal, not an automatic correction. An authoring override was
accepted only where a hydrographic/maritime authority published the explicit
MSL-to-Chart-Datum relationship. The base records within a documented radius
are removed before one authority value is inserted; the exact source, hashes
and removed record IDs are retained in `.xtdt.prv`.

This corrected Auckland, Wellington, Rio/Ilha Fiscal and Reykjavík. Darwin is
an authority control and changed only slightly. The earlier severe Darwin and
Rio results were also audited at the reference level: Darwin's frozen values
were from the wrong month, while Rio's fixture omitted two of the official six
events and used the wrong times. Both fixtures now transcribe the stated
official 21 August rows.

No correction was applied merely to improve a canary. Fishguard, Portsmouth
and Hamburg retain probable absolute-datum biases because a sufficiently
explicit, matching-epoch authority MSL-to-chart-zero value has not yet been
established. Their forecast status remains cautionary rather than silently
tuned.
