# X-Tidal v0.8 position and date qualification — 2026-08-22

## Scope

Version 0.8 makes forecast position and period explicit. A user can select the
live chart cursor, an OpenCPN waypoint or mark, or manual WGS84 coordinates.
The period can be the rolling 48-hour next-tides view or one complete local
calendar date in the selected display time zone. Prediction and XTD sampling
remain UTC.

## Deterministic checks

The clean release test build passed all four CTest targets:

- prediction/runtime tests;
- worldwide official-source canary manifests;
- public canary manifests; and
- TICON-3 import tests.

New regression coverage verifies:

- the rolling window remains 48 hours centred on the selected instant;
- 21 August 2026 in `Europe/London` maps to
  `2026-08-20T23:00:00Z` through `2026-08-21T23:00:00Z`;
- the UK spring clock-change date is a 23-hour forecast window;
- the UK autumn clock-change date is a 25-hour forecast window; and
- signed decimal and N/S/E/W coordinate forms are parsed with strict WGS84

cannot run under the laptop's ptrace-based execution harness, so leak detection
was disabled for that run; address and undefined-behaviour instrumentation
