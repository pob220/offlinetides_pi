# X-Tidal v0.9.1 layout qualification

Date: 2026-08-22

## Defects

The native OpenCPN comparison added in v0.9 increased the dialog's preferred
height beyond the usable desktop on a 1080-pixel display. wxWidgets compressed
the only proportioned child, reducing the curve panel to zero height while the
event list remained visible.

A separate first-run defect treated "no package loaded" as "the loaded package
has no Chart Datum transform". This selected model MSL and persisted it before
the user opened a package.

## Fix and evidence

The dialog content now uses a vertically scrollable virtual layout. The curve
retains its 190-pixel minimum; other forecast and native-comparison information
remains accessible by scrolling on shorter displays. A taller window can still
allocate additional space to the curve.

Package availability and datum capability are now distinct inputs. A fresh
profile defaults to height above Chart Datum. A loaded package which genuinely
lacks a Chart Datum transform still falls back to explicitly labelled model
MSL, and an existing saved user selection remains unchanged.

- Release build and all six CTest groups: passed.
- Fresh portable Test-OpenCPN profile, with no package path or saved height
  reference: logged `initial height reference=chart-datum` and persisted
  `height_reference=0` on clean shutdown.
- Full Test-OpenCPN v0.9 package: chart-datum forecast and native API 1.21
  comparison loaded; the runtime layout canary reported
  `curve_height_px=190`, `curve_min_height_px=190`.
- Visual isolated-host inspection confirmed the curve, axis, HW/LW labels and
  event list are rendered; vertical scrolling exposes the remaining content.
