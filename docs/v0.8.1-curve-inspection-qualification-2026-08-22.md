# X-Tidal v0.8.1 curve-inspection qualification

Date: 2026-08-22

## Result

The displayed tidal curve can now be inspected directly. Moving the pointer
inside the plot draws a vertical crosshair, marks the interpolated curve point
and displays its time and water height. The time uses the selected display
zone while the interpolation instant remains UTC. The value is explicitly
labelled `m CD`, `m MSL` or `m` according to the selected curve datum.

Clicking the curve pins the readout so it survives pointer movement and exit.
Clicking again releases it. Loading another curve, changing position/date or
clearing the forecast also clears the inspection state.

## Implementation boundary

`InterpolateHeightSample` is a transport- and GUI-independent prediction
helper. It linearly interpolates between the two bracketing precomputed curve
samples and refuses to extrapolate outside the displayed forecast window.
The wx panel maps pointer position to a UTC instant and owns only transient
hover/pin state.
