# X-Tidal v1.0 native comparison qualification — 2026-08-22

## Scope

V1.0 adds an optional native OpenCPN tidal-height curve beside the X-Tidal
forecast. The plugin binary remains API 1.21 compatible and discovers the
enhanced station-metadata seam at runtime.

The v1.0.1 layout follow-up adds a bounded two-row graph-header legend: a blue
X-Tidal swatch and a dashed orange native-station swatch with station name and
distance. The label is ellipsized rather than clipped at constrained widths,
the legend is outside the plotting area and the panel minimum is 270 pixels.

The comparison is deliberately fail-closed:

- exact absolute heights require a declared reference-station datum with the
  same typed equivalence key;
- a metric TCD `Z0` may transform the native prediction into the X-Tidal
  display reference, but is labelled as a transform rather than independent
  datum validation;
- all other native curves are vertically mean-aligned and used only for
  timing, range and shape;
- a station farther than 100 NM is rejected and no comparison is displayed.

## Automated evidence

- OpenCPN metadata unit tests: 4/4 passed under the core `-Werror` build.
- Broader core tests: 97/97 passed after excluding the existing environment-
  dependent `IpcClient.*` and `RestServer.*` fixtures. The unfiltered run
  reproduced three unavailable-session IPC failures and the existing
  `RestServer.CheckWrite` allocator abort; no tide test failed.
- X-Tidal CTest: 6/6 passed. Exact-datum, `Z0`, unknown-datum alignment,
  pointer/export and the 100 NM distance guard are covered by the plugin test
  executable.
- ASan/UBSan: the X-Tidal test executable passed with leak reporting disabled
  for the host-library fixture and undefined-behaviour errors fatal.
- The live-catalogue audit checks every configured station for unique combined
  index and stable ID, complete dataset identity/version, valid coordinates,
  finite `Z0`, internally consistent datum status and summary counts.
- The enhanced core and plugin are smoke-tested in the isolated Test-OpenCPN
  profile before installation in the working profile.

matched eight HW/LW events, exercised exact-datum and `Z0` modes, retained a
190-pixel curve, migrated the comparison setting to default-on, and completed

## Operational boundary

The dashed native curve is supporting comparative evidence, not an
observation. X-Tidal never infers datum equivalence from free text, never uses
an unknown datum for an absolute-height difference, and never substitutes a
remote station when none exists within 100 NM.

The candidate hashes matched the copies installed in the isolated
Test-OpenCPN profile.
